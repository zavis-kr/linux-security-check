# linux-security-check
22501013 - 박혜성 취약점 진단 실무 과제 

01.Default 계정 삭제부터 08.shadow파일 권한 설정까지 취약점 진단 스크립트 작성 

## 실행 환경
-macOS의 UTM 가상머신

-CentOS 09.ver

-Bash Shell 

## 파일 구성

-22501013_phs_01.sh ~ 22501013_phs_08.sh: 항목별 진단 스크립트

-22501013_phs_01.txt ~ 22501013_phs_08.txt: 항목별 실행 결과

## 실행 방법
-CentOS 터미널에서 해당 파일이 있는 폴더로 이동한 후 실행

EX : ./22501013_phs_01.sh

각 스크립트는 실행 결과를 txt 파일로 저장합니다.
